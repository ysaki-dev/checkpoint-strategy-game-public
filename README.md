# ROUTE SHIFT — AI対戦版

スマホとPCで遊べるブラウザゲームです。「AIと練習」で開始します。PCはWASD/矢印、スマホは画面内スティックで移動。ルール選択から秘密戦も遊べます。秘密CPは準備30秒内に選べます。未選択ならなし。秘密戦は森林2/通常5タイルの視界と小さな丘陵5か所で読み合い、双方の全得点は終了時に開示します。ノーマルは従来の判断プログラム、エキスパートβは学習済みの小さなニューラルネットです。学習済み重みを同梱し、どちらもAPI/LLM接続なしで端末内で動きます。ページ下部から1ファイル版を保存すればPCのChrome/Edgeでオフラインでも遊べます。

このリポジトリは公開用の配信ファイルのみを管理します。reference/にゲーム理解・方策作成用のルールと評価器のソースを選んで公開しています。開発元のGit履歴・テスト・サーバー・APIキーは含みません。API・課金・ログインは不要です。
