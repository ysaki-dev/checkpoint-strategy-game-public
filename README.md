# ROUTE SHIFT — AI対戦版

スマホとPCで遊べるブラウザゲームです。「AIと練習」で開始します。PCはWASD/矢印、スマホは画面内スティックで移動。ルール選択から秘密戦も遊べます。秘密CPは準備30秒内に選べます。未選択ならなし。秘密戦は森林2/通常5タイルの視界と小さな丘陵5か所で読み合い、双方の全得点は終了時に開示します。AIは機械学習・LLMではなく、ブラウザ内の判断プログラムです。

このリポジトリは公開用の配信ファイルのみを管理します。開発元のソース・テスト・Git履歴・サーバー・APIキーは含みません。API・課金・ログインは不要です。
