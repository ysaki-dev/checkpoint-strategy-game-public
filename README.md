# ROUTE SHIFT — AI対戦版

スマホとPCで遊べるブラウザゲームです。「AIと練習」で開始します。PCはWASD/矢印、スマホは画面内スティックで移動。ルール選択から秘密戦も遊べます。秘密CPを選んでから開始し、森林2/通常5タイルの視界、丘陵の相互可視、終了時に明かされる秘密点で競います。AIは機械学習・LLMではなく、ブラウザ内の判断プログラムです。

このリポジトリは公開用の配信ファイルのみを管理します。開発元のソース・テスト・Git履歴・サーバー・APIキーは含みません。API・課金・ログインは不要です。
